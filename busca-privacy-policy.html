Política de Privacidad - Busca

Última actualización: 28 de agosto de 2026

Busca (com.maxxxi.busca) es un navegador web general que permite buscar y navegar por internet.

Recogida y uso de datos

Busca NO recopila, almacena, ni comparte ningún dato personal del usuario en nuestros servidores. No solicitamos registro, no pedimos nombre, email ni datos de pago.

Al ser un navegador, cuando navegas a páginas de terceros (Google, Wikipedia, etc.), esas páginas pueden recopilar datos según sus propias políticas de privacidad. Busca no controla esas políticas.

El historial de búsqueda y navegación se guarda solo localmente en tu dispositivo para las funciones de historial y marcadores, y no se envía a ningún servidor externo.

Permisos

La aplicación solo solicita permiso de acceso a Internet para navegar. No solicita acceso a contactos, cámara, micrófono o ubicación precisa.

ID de Publicidad y Anuncios

Busca no muestra anuncios propios y no utiliza ID de publicidad.
